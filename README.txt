VENTA DE MUDANZA - WEBSITE FILES

Open index.html to view the saved public storefront.

Folder contents:

- index.html: Primary HTML file and public storefront snapshot.
- _next/: Compiled browser JavaScript and CSS.
- assets/media/: Images currently used by the public storefront.
- inventory/: Static inventory images bundled with the application.
- images/volume-2a and images/volume-2b: Web-optimized copies of the new Volume 2 photos.
- source/: Editable application source, styles, database schema, migrations, and public assets.
- compiled/: Production build, including browser and server files.

Important: The complete working website uses hosted database, image storage, authentication, and server functions. Opening index.html directly provides a saved public view, but administrative tools, checkout, live inventory changes, and other server-backed features require the deployed application.
